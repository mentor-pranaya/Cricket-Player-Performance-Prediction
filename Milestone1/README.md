# IPL Data Acquisition & Exploratory Analysis

## Description
This project performs data acquisition, cleaning, and exploratory data analysis
on Indian Premier League (IPL) cricket datasets.

## Datasets
- deliveries.csv : Ball-by-ball data
- matches.csv : Match-level summaries

## Objectives
- Inspect data quality and schema
- Clean and normalize datasets
- Perform exploratory data analysis
- Visualize trends in runs, wickets, venues, and teams

## Files
- 01_EDA.ipynb : Exploratory Data Analysis notebook
- data_cleaning.py : Data preprocessing script
- requirements.txt : Python dependencies

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

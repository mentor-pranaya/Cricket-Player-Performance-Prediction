IDE: Google Colab

Dataset:

    Name: IPL Ball-by-Ball Dataset (2008–2024)
    Source: Kaggle

Dataset Size:

    Rows: ~250,000+ ball-by-ball records
    Matches: 1,000+ IPL matches
    Columns: ~20–25 delivery and match-level features

Data Type:

    Structured tabular data (CSV)

Key Attributes:

    Match Details: Match ID, season, date, venue
    Player Details: Batter, bowler, batting team, bowling team
    Batting Statistics: Runs per ball, boundaries (4s, 6s), strike events
    Bowling Statistics: Wickets, runs conceded, overs, economy
    Match Context: Opposition team, venue, match result
